# Open Source Practice

A small, community-friendly repository for learning the open-source contribution workflow through focused and reviewable pull requests.

## Goals

- Practice working with forks, branches, commits, and pull requests.
- Keep examples simple enough for first-time contributors.
- Encourage clear documentation and constructive code review.

## How to contribute

1. Fork this repository.
2. Create a branch with a descriptive name.
3. Make one focused improvement.
4. Commit the change with a clear message.
5. Open a pull request explaining what changed and why.

## Contribution ideas

- Improve documentation or correct a typo.
- Add a beginner-friendly programming example.
- Suggest a useful project structure.
- Add tests or explain how to run existing examples.

Please avoid committing secrets, generated files, or unrelated changes.
